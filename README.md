# Коммерческое использование результатов, созданных ChatGPT

**Дата анализа:** 09.06.2026

## Вопрос

Получает ли пользователь права на результаты (Output), созданные ChatGPT по его запросам (промптам), включая изображения, тексты и другие материалы, и может ли использовать их в коммерческих целях?

---

# Краткий вывод

Да.

Согласно действующим условиям использования OpenAI, пользователь сохраняет права на свой ввод (Input), а OpenAI передает пользователю свои права на созданный вывод (Output).

Это означает, что пользователь вправе использовать результаты работы ChatGPT в коммерческой деятельности, включая:

- продажу изображений;
- публикацию книг;
- выпуск комиксов;
- создание курсов;
- использование в рекламе;
- создание программного обеспечения;
- разработку игр;
- создание видеоконтента;
- продажу лицензий на созданные материалы;
- использование в корпоративных проектах.

---

# Что говорят Terms of Use OpenAI

Смысл ключевого положения Terms of Use:

> Вы сохраняете права на Input.
>
> OpenAI передает вам свои права, интересы и долю в Output.

Практически это означает:

| Объект | Кому принадлежат права |
|----------|----------|
| Ваш запрос (Input) | Вам |
| Результат генерации (Output) | Вам |
| Коммерческое использование Output | Разрешено |

---

# Важное ограничение №1

## OpenAI передает права, но не гарантирует авторское право

Необходимо различать два понятия:

### Договорные права

Это отношения между вами и OpenAI.

По договору OpenAI разрешает вам использовать Output без ограничений на коммерческое использование.

### Авторское право

Это уже вопрос законодательства конкретной страны.

В разных юрисдикциях подход отличается:

- США;
- Европейский Союз;
- Великобритания;
- Россия;
- Казахстан;
- Китай и др.

Поэтому факт передачи Output не означает автоматическое признание авторского права на него во всех странах мира.

---

# Важное ограничение №2

## OpenAI не гарантирует уникальность результата

В условиях отдельно указано:

- результаты могут быть похожими;
- другой пользователь может получить аналогичный результат;
- OpenAI не гарантирует эксклюзивность Output.

Следовательно:

- право использования есть;
- право эксклюзивности не гарантируется.

---

# Важное ограничение №3

## Нельзя нарушать права третьих лиц

Даже если изображение создано ChatGPT, остаются общие ограничения законодательства:

Нельзя незаконно использовать:

- товарные знаки;
- защищенных персонажей;
- зарегистрированные бренды;
- чужие произведения;
- коммерческие секреты;
- объекты патентной защиты.

Ответственность за такой контент несет пользователь.

---

# Практические рекомендации по защите своих прав

## 1. Хранить все промпты

Рекомендуется сохранять:

- исходные промпты;
- версии промптов;
- даты генерации.

Это позволяет доказать происхождение контента.

---

## 2. Сохранять промежуточные результаты

Архивировать:

- черновые версии;
- первые генерации;
- доработанные версии;
- финальные материалы.

Это помогает подтвердить историю создания произведения.

---

## 3. Фиксировать творческий вклад человека

Наиболее сильная правовая позиция возникает тогда, когда человек участвует в создании произведения.

Рекомендуется сохранять:

- раскадровки;
- эскизы;
- описания персонажей;
- сценарии;
- редакторские правки;
- макеты.

Чем больше человеческого вклада, тем сильнее позиция в вопросах авторского права.

---

## 4. Вести журнал генераций

Для каждой работы фиксировать:

- дату;
- используемую модель;
- версию промпта;
- автора промпта;
- итоговый файл.

Пример:

| Поле | Значение |
|--------|--------|
| Дата | 09.06.2026 |
| Модель | GPT-5.5 |
| Автор | Иван Иванов |
| Промпт | v12 |
| Результат | image_001.png |

---

## 5. Проверять результат на сходство с известными объектами

Перед публикацией желательно проверять:

- персонажей;
- логотипы;
- бренды;
- фирменные элементы.

Особенно если контент планируется продавать массово.

---

## 6. Закреплять права в договорах

Если генерацией занимаются сотрудники или подрядчики:

- прописывать передачу исключительных прав;
- фиксировать принадлежность промптов компании;
- фиксировать принадлежность результатов компании.

---

## 7. Хранить исходники

Рекомендуется сохранять:

- PSD;
- SVG;
- AI;
- PNG;
- PDF;
- проектные файлы.

Это помогает подтвердить авторство и дату создания.

---

## 8. Регистрировать важные объекты

Для коммерчески значимых проектов рекомендуется:

- регистрация товарного знака;
- депонирование произведений;
- нотариальная фиксация материалов;
- регистрация бренда.

---

# Наиболее безопасная модель использования

Для коммерческих проектов рекомендуется следующий подход:

1. Пользователь самостоятельно формирует идею.
2. Создает подробные промпты.
3. Генерирует результат через ChatGPT.
4. Выполняет собственную доработку.
5. Сохраняет историю создания.
6. Проверяет результат на конфликты с правами третьих лиц.
7. Использует результат в коммерческой деятельности.

При таком подходе юридические риски минимальны.

---

# Итог

На основании действующих Terms of Use OpenAI:

**Пользователь получает права на Output, созданный ChatGPT по его запросам, и вправе использовать такие материалы в коммерческих целях.**

Это относится к:

- изображениям;
- иллюстрациям;
- текстам;
- книгам;
- презентациям;
- программному коду;
- аналитическим материалам;
- иным результатам генерации.

Основные риски связаны не с OpenAI, а с:

- авторским правом конкретной страны;
- правами третьих лиц;
- использованием чужих брендов и объектов интеллектуальной собственности;
- отсутствием доказательств собственного творческого вклада.

При наличии архива промптов, истории генераций и собственной доработки контента правовая позиция пользователя становится существенно сильнее.
